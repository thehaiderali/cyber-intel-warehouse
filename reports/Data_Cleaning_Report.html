1. Cleaning rules applied

  • Remove duplicates - one row per business key (asset_id, cve_id, CVE+score date); first/latest record kept, the rest logged as DQ-DUP.
  • Handle NULL values - missing owner/department -> Unassigned; missing description -> default text; invalid IP -> NULL; missing CVSS -> Unknown member (-1); missing business key -> rejected.

  • Convert data types - text -> DATE / TIMESTAMP / NUMERIC(8,6) / NUMERIC(3,1) / BOOLEAN; software versions stay text (BR-04).
  • Validate business rules - BR-01 CVE ID format, BR-02 EPSS 0-1, BR-03 CVSS 0-10, BR-05 KEV due date >= date added, BR-06 controlled criticality.
